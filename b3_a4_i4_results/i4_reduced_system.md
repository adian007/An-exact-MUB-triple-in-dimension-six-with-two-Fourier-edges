# Reduced I4 system

For a fixed parameter z and a selected third-MUB basis B3={v_1,...,v_6}, write

w = (1,q_1,...,q_5)^T / sqrt(6),   q_j r_j = 1.

Introduce z,t with zt=1. The fourth-vector witness equations are

W_k = (w^* H_{D,k})(H_{D,k}^* w) - 1 = 0,

for the six normalized columns H_{D,k}/sqrt(6), equivalently using the unnormalized H_D columns:

|w^* H_{D,k}|^2 - 6 = 0.

For the third basis:

G_j = |w^* v_j|^2 - 6 = 0,

when v_j is represented unnormalized with first coordinate 1. In a polynomial implementation, introduce inverse variables for every phase variable and replace conjugation on the unit torus by inverse substitution.

The reduced incidence ideal is therefore generated by:

1. zt-1;
2. q_j r_j - 1 for j=1,...,5;
3. the six H_D MU equations;
4. the six MU equations against B3.

The precise minimal generator set can be reduced after choosing an independent chart. The older project formulation used additional auxiliary variables and a 17-equation presentation; this package intentionally records the direct witness equations without claiming minimality.

For exact algebra, the coefficients of B3 must themselves be represented exactly. The present numerical B3 roots are not an exact coefficient field.
