# Construction families and useful anchors

## Fourier anchor

The Fourier matrix `F6` is a high-symmetry CHM. The local benchmark reports 48 physical MU vectors for `{I,F6}` and 16 third-basis cliques. Grassl's maximal-triple result makes this a valuable negative-control anchor, but the symmetry also makes it a poor generic representative.

## Dita anchor

The Dita slice at `theta = arccos(1/sqrt(3))`, `phi = pi/4` produces the project's principal one-dimensional lambda locus. The local results distinguish generic lambda values with 72 physical MU vectors from special D0-equivalent values with 120, and recover third-basis cliques throughout the sampled circle.

The change in constellation size is not evidence of a new fourth MUB. It is evidence that the MU-vector variety has special degenerations at selected lambda values. Those points should be treated as separate strata in any continuation or elimination argument.

## Tao S6 anchor

The isolated Tao order-six CHM is a useful negative control. The local benchmark reports 90 physical MU vectors and no third MUB. It tests whether the pipeline accidentally manufactures cliques from a large MU-vector pool.

## Karlsson family

The family `K_6(theta,phi,lambda)` is a three-parameter CHM family. The current project has identified a bounded F6-type arc at `theta=0` and a Dita lambda circle as reproducing third-MUB loci. The locus classification is computational, not a theorem about all parameter space.

## Construction principle for the next phase

Every proposed new anchor should carry:

- an exact or high-precision parameter description;
- a CHM residual and dephasing convention;
- a fresh per-H pool solve;
- exhaustive clique enumeration;
- independent high-precision re-verification;
- a fixed `B3` witness record.

This prevents a construction formula from being mistaken for a family-wide extension theorem.
