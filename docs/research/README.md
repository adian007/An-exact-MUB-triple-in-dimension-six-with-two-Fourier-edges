# Research dossier: MUBs in dimension 6

Date: 2026-09-17

This dossier is a literature-backed research map for the question whether a pair `{I,H}` in dimension 6 can extend to four mutually unbiased bases, with the present computational emphasis on Karlsson's family `K_6^(3)`.

## Bottom line

The mathematically useful target is not a global claim about all complex Hadamard matrices. It is a layered program:

1. certify the exact scope and gauge conventions;
2. establish complete MU-vector pools for fixed `H`;
3. enumerate every third-basis clique;
4. exclude the one-vector fourth-basis witness for every clique;
5. only then attempt parameter-family elimination or interval covering.

The local project has already achieved strong results at selected Dita points and broad numerical support, but the family-wide absence theorem remains open. The new notes below are deliberately split by evidence type.
