# Symbolic I3 branch ideal

For six vectors v_a=(1,x_{a1},...,x_{a5})/sqrt(6), introduce inverse variables y_{aj}.
The branch ideal consists of six copies of the single-vector MU ideal plus pairwise orthogonality equations.

For a<b, impose <v_a,v_b>=0 and its conjugate. In algebraic form:

`sum_j y[a,j]*x[b,j] + 1 = 0` and `sum_j x[a,j]*y[b,j] + 1 = 0`, with x*y=1.

A third-MUB branch is a six-vector fiber of this ideal whose projection to z is nonempty.
