# Fold and A4 Orbit Computation — Dimension-6 MUB / Diţă Circle

## Goal

This package implements the next computational object in the dimension-6 MUB project: direct numerical investigation of the singular MU-vector locus at

`lambda* = 0.1114802243779665542913031975274172717685818097497045...`

and its action under the previously verified fixed-parameter monomial symmetry group generated by `G2` and `G3`.

The computation uses **columns** of `H_D(lambda)` for the MU equations, matching the symbolic `I3_equations.py` construction. This orientation correction is important: using rows changes the numerical system and invalidates a symmetry comparison.

## Mathematical object

For `v=(1,x1,...,x5)/sqrt(6)` with `|x_j|=1`, define six real MU equations

`F_k(v,lambda) = |h_k^* v_unscaled|^2 - 6`.

In phase coordinates `x_j=exp(i a_j)`, the system is evaluated as six real equations in five phase variables. The singularity is detected through the rank deficiency of the 6x5 Jacobian with respect to the five phase variables.

The target parameter is

`lambda* = 0.1114802243779665542913031975274172717685818097497045...`.

Known numerical pool counts to reproduce are approximately 120 below the fold and 72 above it. At the critical parameter, 24 double roots are expected in addition to 72 regular roots, giving 96 distinct roots.

## Important status warning

This package is an **exploratory numerical computation**, not a proof that the 24 singular roots exist with exact multiplicity, and not a proof that the generic stabilizer has exactly 12 elements. HomotopyContinuation.jl certification is designed for nonsingular solutions; its documentation explicitly notes that `certify` certifies isolated nonsingular zeros using interval/Krawczyk methods. Singular roots therefore require a separate treatment rather than being declared certified merely because a numerical solver converged. See the official documentation: https://www.juliahomotopycontinuation.org/HomotopyContinuation.jl/stable/certification/

## Expected research progression

1. Reproduce below/critical/above pool counts.
2. Isolate the 24 singular roots with a square augmented singular system or deflation.
3. Apply the A4 generators to the isolated roots.
4. Determine orbit sizes and stabilizers.
5. Repeat the symmetry quotient on actual third-MUB cliques `B3`.
6. Only then attach the fourth-vector incidence ideal `I4`.

## Current run (2026-09-28)

A 1200-start critical search recovered exactly 96 distinct numerical solutions at `lambda*`. A finite-difference Jacobian SVD identifies 24 candidates with `sigma_min < 1e-4`, while the remaining solutions have a large gap in the smallest singular value. This reproduces the expected `72 + 24 = 96` numerical decomposition. The 24 candidates are **not yet certified singular roots**; the next implementation should solve a square singular/deflated system.

The first A4 action test is retained in `results/a4_singular_action.json`. Because the singular candidates are currently only approximate and the fixed-z group has not been proved complete, this file is diagnostic rather than a theorem.
